A fast drop-in for make.fun's csv-reader 1.0.0: `solve.js` reads broken CSV files and returns exactly the reference's `{columns, rows, errors}` — BOM, CRLF/LF record ends, stray CRs, quoted fields with doubled quotes, quote junk, unterminated quotes, short/long rows — several times faster than the reference by slicing fields out of the text instead of building them a character at a time.

## Run it

```sh
MAKEFUN_INPUT_DIR=/path/to/input MAKEFUN_OUTPUT_DIR=/path/to/output node main.ts
```
